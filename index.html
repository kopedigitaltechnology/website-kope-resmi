Kebijakan privasi

Privasi Anda penting bagi KOPE Technology. Ringkasannya:

Data yang kami kumpulkan

Saat membuat akun: nama dan email. Saat mendaftar uji coba beta: nama lengkap, nomor HP, Gmail, jenis kelamin, alamat rumah (boleh dikosongkan), dan foto selfie verifikasi. Kami tidak menyimpan nomor kartu. Kata sandi dikelola Firebase, bukan oleh website ini.

Untuk apa data dipakai

Kami mengumpulkan data Anda untuk menjaga situs dan produk uji coba dari virus dan dari orang yang mencoba mengakses perusahaan tanpa izin, memeriksa pendaftar uji coba beta, dan menanggapi permintaan Anda. Data tidak dijual dan tidak dibagikan untuk iklan.

Foto selfie

Foto hanya dipakai untuk verifikasi dan hanya bisa dilihat admin. Foto dihapus otomatis dari server saat admin menerima, menolak, atau menghapus permintaan Anda, atau saat Anda menghapus permintaan atau akun sendiri. Selama permintaan belum diputuskan, foto tetap tersimpan.

Di mana data disimpan

Di layanan Google Firebase. Data hanya bisa dibaca oleh Anda dan admin KOPE yang berwenang.

Berapa lama

Data uji coba disimpan selama program uji coba berjalan atau sampai Anda menghapusnya.

Hak Anda

Anda dapat melihat status dan menghapus permintaan uji coba, permintaan lain, atau seluruh akun Anda sendiri (halaman Uji Coba Beta dan menu Akun Saya). Untuk bantuan lain, hubungi kami lewat kontak resmi di bagian Lokasi.

Pengaturan keamanan

Firebase App Check (reCAPTCHA v3)

Memuat…

Isi hanya Site Key (kunci publik). Secret Key jangan ditaruh di sini atau di kode. Tempel Secret Key di Firebase Console, App Check, aplikasi web, reCAPTCHA v3. Hanya admin yang bisa menyimpan atau menghapus Site Key.

Penting: kalau Site Key hanya disimpan di sini, jangan tekan Enforce untuk Firestore di Firebase Console. Kunci dibaca dari database yang sama, jadi pengunjung baru bisa gagal memuat data. Untuk perlindungan penuh (Enforce), isi juga APPCHECK_SITE_KEY di app.js. Site Key bersifat publik, bukan rahasia.
